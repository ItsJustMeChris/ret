# v0.1.15

## Changes

- [x] Added: OpenCode as an agent beside Codex and Claude Code, turned on by itself where it's installed, plus a custom agent: any agent with an Agent Client Protocol mode (Gemini CLI, Goose, GitHub Copilot, Qwen Code, Cursor…), started by the command you give in Settings.
- [x] Added: Notes, a window on the canvas (from its menu or Open Notes in the palette). Keep notes in Ret, in a folder of Markdown files you add, or in a project's .ret/notes where its agents can read them. Start a thread from a note, or add one to a thread's message.
- [x] Added: Claude Code's subagents show as threads under the thread that spawned them, as Codex's do, with their own approvals and Stop.
- [x] Changed: Claude threads show each turn's changes, real diffs, context use and token totals as soon as they open, the model by name, and the title Claude Code gives a session.
- [x] Changed: The Inbox and Code windows on the canvas look and work exactly like Inbox and Code mode, under a window title bar.
- [x] Fixed: Terminals start on macOS.
- [x] Fixed: Sending on a Claude thread without touching the model chip keeps its model and effort, plan mode works with Claude Code, and failed Claude requests show as errors rather than replies.
