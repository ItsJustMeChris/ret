# v0.1.13

- [x] Added: Terminals in every view: a panel under each thread in Focus, Code and the Inbox, and terminal windows of their own on the canvas. Ctrl+` shows or hides the current thread's terminal, Ctrl+Shift+` opens another.
- [x] Added: Terminals run without Codex, open in the thread's folder on the device it runs on (paired devices included), and keep running as you switch modes, tabs and windows.
- [x] Added: One composer chip sets the model, reasoning effort and speed on desktop and mobile, with Claude Code's fast mode offered on models and accounts that support it.
- [x] Changed: The Ret bot moves through several animation loops for each mood, the same on desktop and mobile.
- [x] Changed: Updated desktop and mobile dependencies, including TypeScript 7 and Expo SDK 58.
